# Document Management System

A comprehensive document management system with a NestJS backend and RAG-based Q&A capabilities. This system provides robust document management features along with an intelligent question-answering system based on the managed documents.

## Project Structure

The project consists of two main components:

### 1. NestJS Backend (`/nestjs-project`)

A full-featured document management backend built with NestJS, providing:

- User Authentication & Authorization
- Document Management & Version Control
- Document Ingestion Pipeline
- RESTful API Interface

For detailed information about the NestJS backend, please refer to the [NestJS Project README](/nestjs-project/README.md).

### 2. RAG-based Q&A System

An intelligent question-answering system that:

- Processes and indexes managed documents
- Utilizes Retrieval Augmented Generation (RAG) for accurate answers
- Provides context-aware responses based on document content

## Getting Started

1. Set up the NestJS backend by following the instructions in the [NestJS Project README](/nestjs-project/README.md)
2. Configure the RAG system (documentation coming soon)

## Features

- **Document Management**
  - Secure document storage and retrieval
  - Version control and change tracking
  - Access control and permissions
  - Document metadata management

- **Intelligent Q&A**
  - Context-aware document search
  - Natural language question processing
  - RAG-based answer generation
  - Source attribution for answers

- **Security**
  - Role-based access control
  - Document-level permissions
  - Secure API endpoints
  - Audit logging
